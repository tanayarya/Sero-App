# Sero

Local document chat for macOS using Ollama.

## What it does

- Chat with `PDF`, `TXT`, and `Markdown` files in a focused macOS app.
- Keep document conversations private with local Ollama models on your Mac.
- Connect to another Ollama server if your models live on a different machine.
- Get document grounded answers, summaries, and quick takeaways from your own files.

## Requirements

- macOS 14 or later
- Ollama running on this Mac or available on another machine

## Quick start

1. Open Sero.
2. Choose `Use this Mac` or `Use another server`.
3. Download or select a chat model.
4. Import a document and start chatting.

This app is not notarized by Apple yet. You may see a macOS warning and may need to open it manually from Finder or System Settings.

## Build from source

1. Clone this repository.
2. Open `product-atom.xcodeproj` in Xcode.
3. Run the `product-atom` scheme.
